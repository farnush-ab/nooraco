# Nooraco · نوراکو

Editorial, animated, RTL-Persian brand site for **Nooraco** — industrial sewing machine parts (PIN · STRONG H).

Built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, **Lucide** icons.
Design follows the official Nooraco Brand Guideline palette (`#102b42 → #ebebee`) and Dooran/Vazirmatn typography.

## Getting started

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — lint
